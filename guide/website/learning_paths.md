# Learning Paths
This website was made both to be a reference and to aid researchers into writing their own Data Management Plans.
The challenge this poses is that, to be a reference, each topic should be contained in its own page, while to be an effective teaching tool, a more long-form, coherent text is needed.

Learning paths are designed to bridge this gap.
Depending on your use-case, they provide a list of pages, in the order they should be read in, to achieve your goal.

## Write your Data Management Plan
- 🎯 **Audience**: Beginners
- 🥅 **Goal**: Write your first data management plan

This learning path is great if you have never written a data management plan before, you are not familiar with what data management even is, and are looking for a complete, step-by-step tutorial on what to do.

### Page order
This is by far the easiest learning path - simply read through all the guide from top to bottom, following the order on the sidebar.
